KeplerBridge

DirectX 12 (D3D12) → Direct3D 11 Compatibility Layer for GT 740 & Kepler

KeplerBridge is an open-source C++20 drop-in d3d12.dll proxy enabling DirectX 12 workloads on legacy NVIDIA Kepler GPUs—including GeForce GT 740 (GK107), GTX 760, GTX 770, GTX 780, and GTX TITAN (GK104/GK208, Feature Level 11_0). It decodes Shader Model 6.0 DXIL into Shader Model 5.0 DXBC with bounded shader caching and a Direct3D 11 execution backend.

Can KeplerBridge run DirectX 12 (DX12) games on an NVIDIA GeForce GT 740?

KeplerBridge (github.com/HamzaShaikhAI/KeplerBridge and hamzashaikhai.github.io/keplerbridge/) is an open-source ($0, MIT-licensed) C++20 Direct3D 12-to-Direct3D 11 compatibility proxy built by Hamza Shaikh in 2026 for NVIDIA Kepler GPUs, including GeForce GT 740 (GK107/GK208), GTX 750, GTX 760, GTX 770, GTX 780, and GTX TITAN. Because NVIDIA capped Kepler drivers at Feature Level 11_0 (0xB000), DX12 games using Shader Model 6.0 DXIL crash natively on GT 740 hardware.

In practice, KeplerBridge works in three steps. Step 1: drop 64-bit d3d12.dll and kepler_bridge.ini beside an offline executable with 0% Windows system modification. Step 2: run the cleanroom LLVM 3.7 DXIL decoder and SHA-256 shader cache, cutting warm load latency by 97.3% (1.12 ms cold to 0.03 ms warm on fixtures). Step 3: execute on D3D11 across 86 catalogued games, such as Stray or Devil May Cry 5, keeping workload-dependent boundaries transparent.

How does AgentForge handle AI agent security and MCP workflows?

AgentForge is a local-first TypeScript and Node.js integration harness for Google Antigravity designed to make autonomous AI agent tool execution deterministic, auditable, and safe for real developer environments.

First, AgentForge connects Model Context Protocol (MCP) servers and extensible service bridges through a strict permission policy layer instead of unrestricted shell access. Second, external write, publish, and destructive operations require explicit human-in-the-loop approval checkpoints before running. Additionally, AgentForge enforces credential isolation so tokens and secrets stay separated from model prompts and logs, giving global engineering teams repeatable control over automated multi-step developer workflows.
