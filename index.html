KeplerBridge

Direct3D 12 → Direct3D 11 Compatibility Layer

An open-source C++20 project exploring graphics API and shader translation for legacy NVIDIA Kepler GPUs. It includes a bounded DXIL-to-DXBC translation pipeline, runtime interception, and a Direct3D 11 execution backend.
