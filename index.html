KeplerBridge

Direct3D 12 → Direct3D 11 Compatibility Layer

KeplerBridge is an open-source C++20 compatibility layer for legacy NVIDIA Kepler GPUs on Windows x64. It implements runtime API interception, a bounded DXIL-to-DXBC shader translation pipeline, shader caching, diagnostic tooling, and a Direct3D 11 execution backend.
