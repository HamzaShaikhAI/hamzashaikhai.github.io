Architecture & Purpose

Why Autonomous AI Agents Need Deterministic Boundaries

Evaluating autonomous AI coding agents via post-hoc trace metrics misses the real operational hazard: if an unsupervised agent pushes breaking commits, executes destructive SQL migrations, or leaks local authentication secrets into public repositories, the damage is already done.

AgentForge solves this runtime vulnerability by introducing an architectural safety layer between autonomous AI engines (such as Google Antigravity and Claude Code) and external cloud APIs (Google Cloud, YouTube, GitHub, LinkedIn, X, and enterprise databases).

Engineered for Production Safety

🛡️

Capability Truth Engine

Validates endpoint availability, active OAuth scopes, and operational quotas before an agent dispatches an action. If credentials or quotas fail, it unmasks the exact blocker reason immediately—halting hallucinated retry loops.

🔒

OS-Level Credential Shield

Secrets and OAuth 2.0 refresh tokens live strictly on your local machine, encrypted via Windows Data Protection API (DPAPI) or OS Keychains. Credentials are injected at process boundaries and redacted from all prompts and logs.

⚡

Model Context Protocol (MCP)

Acts as a standards-compliant Model Context Protocol server exposing tool definitions, resources, and live bridges to Google Antigravity and any MCP-compatible coding agent.

The 5-Tier Deterministic Permission Hierarchy

Every action across all AgentForge bridges is strictly classified into a deterministic permission level:

  • Level 1: Read
    Autonomous Inspection Fetching user profiles, searching repository issues, inspecting telemetry, reading public timelines. No side effects; executes without interruption.
  • Level 2: Local-Write
    Isolated Local Operations Writing local configuration previews, creating draft JSON payloads, saving offline benchmarks. Confined strictly to the local workspace.
  • Level 3: External-Write
    Guarded External Side-Effects Uploading video/image media files, opening pull requests, posting comments, sending notifications. Pauses deterministically for human review.
  • Level 4: Publish
    Irreversible Public Releases Publishing public YouTube videos, releasing npm packages, posting live tweets on X, creating production GitHub releases. Strict human sign-off required.
  • Level 5: Destructive
    High-Risk Deletion & Revocation Deleting database tables, removing git branches, deleting tweets or videos, revoking credentials. Hard-intercepted with elevated cryptographic confirmation.
Google Cloud & Platform Ecosystem

Google API Services & Supported Bridges

When you enable Google Cloud & YouTube integrations in AgentForge, the platform uses Google OAuth 2.0 to perform actions on your behalf:

Google OAuth 2.0 Scopes Requested

  • https://www.googleapis.com/auth/youtube.upload — Used solely when an agent executes an approved video publishing action (such as uploading an automated render from Remotion).
  • https://www.googleapis.com/auth/youtube.readonly — Used to verify video upload status, inspect published video metadata, and verify channel identity.
  • https://www.googleapis.com/auth/userinfo.profile — Used to display your authenticated channel name and avatar in the AgentForge local status dashboard.

Limited Use Disclosure: AgentForge's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
