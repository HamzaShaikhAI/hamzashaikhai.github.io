AGENTFORGE LEGAL

Privacy Policy

Effective Date: November 15, 2026 · Version 1.0.0 · Application: AgentForge

This Privacy Policy describes how AgentForge (developed and maintained by Hamza Shaikh / @HamzaShaikhAI) handles user data, authentication credentials, and platform interactions when you use the AgentForge CLI, Model Context Protocol (MCP) server, or integration bridges.

Google API Services User Data Policy Compliance:
AgentForge's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

1. Core Architecture: Local-First & Zero External Telemetry

AgentForge is engineered from the ground up as a local-first, open-source software application. Unlike cloud-hosted SaaS agent platforms, AgentForge runs exclusively on the user's local operating system (Windows, macOS, or Linux).

  • No Central Proxy Servers: AgentForge does not operate intermediate servers or proxy infrastructure. When an action is executed, network requests are dispatched directly from your machine to the respective API endpoint (e.g., Google/YouTube, GitHub, LinkedIn, X).
  • Zero Credential Harvesting: Your API keys, access tokens, client secrets, and refresh tokens are stored locally on your device and are never transmitted to the software author or any third party.
  • Zero Tracking or Analytics: AgentForge contains no telemetry SDKs, analytics beacons, or third-party advertising trackers.

2. Information Accessed & How It Is Used

When you explicitly enable and authenticate an integration bridge in AgentForge, the application accesses only the minimum necessary data required to fulfill your requested agent operations:

A. Google & YouTube API Data

If you connect Google Cloud or YouTube credentials to AgentForge, the following scopes and data are accessed:

  • https://www.googleapis.com/auth/youtube.upload — Used solely to upload video files and associated metadata (title, description, tags, privacy status) generated or approved by you.
  • https://www.googleapis.com/auth/youtube.readonly — Used to retrieve upload status, video processing telemetry, and channel playlist information to confirm that an operation succeeded.
  • https://www.googleapis.com/auth/userinfo.profile — Used to display your authenticated channel name and avatar inside your local AgentForge dashboard.

B. Other Third-Party Platforms (GitHub, LinkedIn, X / Twitter)

For connected services like GitHub, LinkedIn, and X, AgentForge accesses user identity, feed search, and content publishing endpoints strictly to perform tasks that you or your autonomous AI agent explicitly authorize.

3. How Data and Credentials Are Stored & Protected

AgentForge implements defense-in-depth security measures to protect your credentials at rest and in transit:

  • OS-Native Encryption: On Windows, tokens are encrypted using the Windows Data Protection API (DPAPI) tied to your Windows user account master key. On macOS and Linux, tokens utilize the OS Keychain or Secret Service.
  • Secret Redaction: AgentForge automatically redacts authorization tokens, client secrets, and passwords from all AI prompt contexts, debug console outputs, and execution logs.
  • Transport Layer Security: All API communications use HTTPS (TLS 1.3) directly to verified provider endpoints.

4. Data Sharing, Sale & AI Model Training

We maintain an uncompromising stance on data privacy:

  • No Sale of Data: AgentForge will never sell, rent, monetize, or trade your personal data, API tokens, or content to any third party under any circumstances.
  • No Unauthorized Third-Party Transfer: Data received via Google APIs or other bridges is never transferred to external databases, advertising networks, or data brokers.
  • No AI Model Training on Private Data: AgentForge does not use your Google user data, YouTube videos, or private codebases to train, fine-tune, or improve any generalized AI models.

5. User Control: Revocation & Complete Data Deletion

You maintain absolute ownership and control over your accounts and credentials at all times:

  • Revocation via AgentForge CLI: You can disconnect and delete any provider's stored credentials instantly by executing:
    npx agentforge auth revoke <provider>
  • Revocation via Google Account: You can revoke AgentForge's access to your Google Account at any time by visiting Google Account Permissions (myaccount.google.com/permissions).
  • Manual File Deletion: Deleting the local directory at %APPDATA%\AgentForge\auth permanently deletes all tokens and configuration files from your system.

6. Children's Privacy

AgentForge is a software development and autonomous agent orchestration tool intended for developers and engineers. It is not intended for use by individuals under the age of 13. We do not knowingly collect personal information from children.

7. Changes to This Privacy Policy

Any updates to this Privacy Policy will be published at this URL (https://hamzashaikhai.github.io/agentforge/privacy/) and documented in the official AgentForge GitHub repository releases. Continued use of AgentForge following any updates constitutes acceptance of the revised policy.
