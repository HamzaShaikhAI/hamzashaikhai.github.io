MCP at Two Years: Tasks, Elicitation, Skills & Deterministic Safety Gates

By Hamza Shaikh (@HamzaShaikhAI) · November 25, 2026 · 6 min read

Executive Answer: Async MCP Governance at Scale

Two years after Anthropic introduced the Model Context Protocol on November 25, 2024, MCP has crossed 700 million monthly SDK downloads across more than 10,000 public connectors under the Linux Foundation's Agentic AI Foundation. In late November 2026, MCP Tasks and Elicitation reached General Availability alongside Skills over MCP in public beta and Google Workspace managed MCP servers. These primitives move agents beyond synchronous request-response calls into background jobs, mid-execution user confirmations, and on-demand playbooks. However, pausing mid-task or invoking asynchronous APIs creates replay and credential exposure risks when authorization lives inside prompt text. AgentForge v1.1.0 addresses this gap with a local-first TypeScript 5.6 runtime offering 52 curated MCP presets, a deterministic five-tier permission model from read to destructive, Windows DPAPI and AES-256-GCM vaults, and a SHA-256 audit ledger that isolates OAuth tokens from untrusted payloads.

What Shipped for MCP’s Second Anniversary

Between November 24 and November 25, 2026, the MCP ecosystem crossed several concrete infrastructure milestones following the stateless 2026-07-28 HTTP specification:

  • 700M+ Monthly SDK Downloads: Over 5 billion cumulative installs across Python, TypeScript, C#, Rust, and Ruby SDKs, backing more than 10,000 public connectors.
  • Tasks & Elicitation (GA): Servers can now return task handles for long-running background jobs instead of blocking connections, and pause mid-request to elicit structured input or explicit user confirmation.
  • Skills over MCP (Public Beta): Servers publish dynamic playbooks alongside tools so models load workflow instructions on demand instead of bloating base prompts.
  • Google Workspace MCP (GA): Managed servers and CLI access for Gmail, Drive, Docs, Sheets, Slides, Calendar, Chat, and Tasks launched on November 24, 2026 with a 5,000 requests/day/project/product free Standard Tier and Model Armor confirmation gates.

Why Async Tasks & Elicitation Need Host-Side Gates

Synchronous tools/call made authorization deceptively simple: one prompt turn, one tool invocation, one result. With MCP Tasks and Elicitation, state now spans minutes and crosses user-interaction boundaries.

If an untrusted remote server triggers a mid-flight elicitation prompt or resumes an asynchronous job handle after context compaction, a naive client cannot tell whether an action was originally scoped as read-only or an external mutation. Likewise, loading dynamic playbooks via Skills over MCP means instructions themselves become runtime inputs that must never inherit ambient OAuth credentials.

How AgentForge v1.1.0 Enforces the Boundary

AgentForge (v1.1.0, MIT, 508/508 Vitest tests passing) enforces capability boundaries in deterministic TypeScript host code rather than prompt instructions:

  • 5-Tier Policy Classifier: Every bridge and MCP action is typed as read, local-write, external-write, publish, or destructive, halting external mutations at operator approval checkpoints.
  • OS-Encrypted Vaults: Tokens reside in %APPDATA%/AgentForge/auth/ via Windows DPAPI (CryptProtectData) or AES-256-GCM, scrubbed from logs and errors before reaching the model.
  • Non-Repudiable Audit Ledger: Forward-linked SHA-256 hash chains and DAG workflow replay guards prevent duplicate non-idempotent executions across async retries.
